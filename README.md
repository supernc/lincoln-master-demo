# Lincoln Master CRM Demo

林肯大师 CRM 系统 POC 演示项目，基于 React + TypeScript + Ant Design Pro Components 构建。

## 功能模块

- **线索管理** — 线索创建、自动分配规则、跟进记录、AI跟进摘要、企微沟通、客户建档
- **客户管理** — 客户档案、标签体系、战败/休眠流程、完整时间线
- **预约到店** — 预约管理、状态流转、企微自动通知
- **试乘试驾** — 试驾预约、拍照上传、客户评价、档案同步
- **客流管理** — 到店登记、数字签到码、有效/无效客流标记
- **待办中心** — 自动生成待办、逾期分级提醒、闪烁告警
- **消息中心** — 8种消息类型、角色权限审批、未读消息联动
- **售后服务** — 售后线索、售后预约(DMS同步)、事故出险管理、售后客户档案

## 技术栈

- React 18 + TypeScript
- Ant Design 5 + Pro Components
- Vite
- React Router 6
- localStorage Mock 数据

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:3000
